# El viaje de los corazones

Versión del Colegio Metodista Robert Johnson, Alto Hospicio.

Juego para educadoras y educadores de educación parvularia. Facilita conversación, empatía y toma de decisiones en grupo. No diagnostica ni sustituye una intervención profesional.

Esta copia es independiente de la versión general. El escudo del colegio reemplaza las marcas anteriores y no incluye la opción de personalizar.

En cada pantalla, abajo y al centro: Psicóloga Alejandra Bravo Pino.

No se piden nombres de estudiantes. El avance queda en el dispositivo.

## Desarrollo

```bash
npm install
npm run dev
```

Requiere Node 22.
